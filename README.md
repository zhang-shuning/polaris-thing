# Cataclysmic Holes!

### This is a 2d platformer, with black holes that pull you towards them. It's pretty self explanatory IMO.

### Controls: (also found in game)

Jump: up/C

Left: left

right: right

Slow Fall: z

Fast Fall: x/down

Restart: hold r

## creation information
This project was built for hackclub polaris entirily in pygame-ce, moslty in one file for time constraint with the prompt... something something gravity patience.

This is the first time that I used a lower level game engine. Instead of features like floor detection, collision in general and movement being built in, there are really only textures and polygons. ~~I only lost like... 20 hours of sleep on this.~~

## How to play!

### From source:
1. Clone the repo
2. Install pygame-ce
3. Run main.py!

### Windows:
1. Download from releases
2. Unzip
3. Run main.exe
